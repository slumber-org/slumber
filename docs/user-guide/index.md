# User guide

This section describes how to work with SLUMBER from a researcher's perspective — creating a study package, validating configs, and running a condition locally.

## Pages in this guide

- [Study Setup](study-setup.md) — study folder layout and `slumber study init`
- [Config Validation](config-validation.md) — `slumber study validate`, error format
- [Run Layout and Logging](run-layout-logging.md) — run directory layout, placeholders, loguru handlers
- [Running a Study](study-run.md) — local run lifecycle and demo walkthrough
- [Participant UI](nicegui-ui.md) — GUI AppFrame, layouts, and activities
- [CLI Reference](../reference/cli-reference.md) — core commands and options

Backend features (auth, scheduling, condition sync) belong in optional extensions and are not required for local `study run`.
